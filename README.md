# nandu: Nandagopal Asok portfolio

A static portfolio site (HTML + CSS + JavaScript, no build step).

## Files
- `index.html`: page structure and content
- `css/style.css`: all styles (dark and light themes via CSS variables)
- `js/script.js`: loader, theme toggle, menu, animations, resume viewer
- `assets/`: resume page images shown in the pop-up viewer
- `Nandagopal_Asok_Resume.pdf`: full resume (opened by "Open PDF")

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` in this folder.

## Deploy on GitHub Pages
1. Create a public repo and upload everything in this folder (keep the folder structure).
2. Settings, Pages, Deploy from a branch, `main`, `/ (root)`, Save.

## Updating your resume
Replace `Nandagopal_Asok_Resume.pdf` and the two images in `assets/` (export each PDF page as a JPG).
